# WordPress Connection Troubleshooting

## Purpose
Resolve common WordPress connection issues quickly during onboarding.

## When to use
- Connector installation fails.
- Workspace does not move to verified state.
- Sync checks are inconsistent.

## Triage sequence
1. Confirm connector is installed and active.
2. Confirm workspace targeting is correct.
3. Confirm environment can make outbound requests.
4. Confirm no plugin conflict is blocking connector actions.
5. Re-run verification and capture logs.

## Common issues
- **Pending forever**: workspace not mapped correctly.
- **Activation error**: hosting restrictions or incompatible environment.
- **Sync timeout**: outbound network policy or intermittent provider issues.

## Expected result
Issue root cause identified and connection either verified or escalated with clear diagnostics.

## Escalation package
Share with support:
- Workspace name
- Site URL
- Timestamp of failure
- Screenshot of status panel
- Any server/plugin logs available
