# Pilot Onboarding Flow

## Purpose
Define how pilot customers move from setup to measurable operational adoption.

## When to use
- New pilot engagements.
- Controlled rollout before full production expansion.

## Flow steps
1. Pilot scope definition (workspaces, workflows, success metrics).
2. Connection and verification (WordPress/Next.js path).
3. Guided enablement (operators + support alignment).
4. Pilot execution window with weekly checkpoints.
5. Pilot review and expansion decision.

## Expected result
Clear pilot outcomes with go/no-go decision for expanded rollout.

## Troubleshooting
- Scope creep: lock pilot boundaries and defer extras.
- Low adoption: improve enablement and ownership.
- Blocked outcomes: escalate dependencies with timeline impact.
