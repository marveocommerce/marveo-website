# Guided Onboarding Playbook

## Purpose
Provide support officers a repeatable process for onboarding customers into Marveo.

## When to use
- New customer onboarding.
- Re-onboarding after infrastructure changes.

## Playbook steps
1. Discovery call: current stack, goals, launch timeline.
2. Connection path selection: WordPress, Next.js, or mixed environment.
3. Setup execution: connector/adapter install + workspace mapping.
4. Verification: run connection and health checks.
5. Operational handoff: ownership, support channels, launch plan.

## Expected result
Customer reaches verified operational state with clear next actions and ownership.

## Troubleshooting
- Unclear ownership: assign primary technical and operational contacts.
- Delayed setup: split onboarding into milestone checkpoints.
- Repeated technical blockers: trigger escalation early with evidence.

## Success criteria
- [ ] Workspace verified
- [ ] Key workflows confirmed
- [ ] Handoff complete
- [ ] Launch readiness process started
