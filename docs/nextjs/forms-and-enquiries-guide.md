# Forms and Enquiries Guide (Next.js)

## Purpose
Standardize how form submissions and enquiries are handled operationally.

## When to use
- You are setting up lead capture or contact forms.
- Support needs predictable handoff for incoming enquiries.

## Setup steps
1. List forms and expected destination workflows.
2. Define required fields and validation rules.
3. Set response ownership (team/person/SLA target).
4. Confirm acknowledgement messaging for end users.
5. Test form flow end-to-end in staging.

## Expected result
- Form data is captured consistently.
- Operational owners can track and respond reliably.

## Troubleshooting
- Submissions missing: verify destination workflow mapping.
- Duplicate entries: review retry and client-side submit behavior.
- Delayed response: review ownership and SLA process.
