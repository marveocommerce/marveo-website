# Marveo Glossary

## Purpose
Create a shared language for product, support, and implementation teams.

## Terms

### Workspace
The primary operational container in Marveo where connected systems, workflows, and ownership are managed.

### Connector (WordPress)
Integration component used to connect an existing WordPress site to a Marveo workspace.

### Adapter (Next.js)
Integration component used to connect a Next.js project to Marveo for operational workflows and visibility.

### Verification
The confirmation step where Marveo validates that a connected environment is healthy and ready.

### Guided Onboarding
Support-assisted setup path for teams that need implementation help and launch coordination.

### Handoff
Transition from onboarding/setup to steady-state support and operations ownership.

### Launch Readiness
Final quality and operational checks before go-live.

### Operational Workflow
A repeatable process (for example content updates, enquiries, approvals, or deployment checks) managed within the workspace model.

### Escalation
The process of routing unresolved issues to a higher support or technical tier.

### Pilot
A controlled initial rollout used to validate outcomes before broader expansion.

## Notes
- Keep definitions outcome-focused and non-technical where possible.
- Add terms as new product capabilities are introduced.
