# Install Marveo Connector (WordPress)

## Purpose
Install and activate the Marveo connector to allow workspace-level operational integration.

## When to use
- During first-time WordPress onboarding.
- During migration from manual processes to connected workflows.

## Setup steps
1. Sign in to WordPress admin.
2. Go to plugin installation.
3. Upload or install the Marveo connector package provided by your onboarding flow.
4. Activate the plugin.
5. Return to Marveo and continue the connection flow.
6. Confirm connector status shows active.

## Expected result
- Connector appears as active in WordPress.
- Marveo can detect connector presence and proceed to verification.

## Troubleshooting
- Activation fails: confirm PHP/WP version compatibility with your support team.
- Plugin not visible after install: clear plugin cache and refresh admin.
- Permission denied: verify file write access for plugins directory.

## Notes
- If a new connector release is required, support will provide the approved version.
- Planned: version health indicator in workspace UI.
