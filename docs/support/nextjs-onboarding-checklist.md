# Next.js Onboarding Checklist

## Purpose
Give support and implementation teams a practical readiness checklist for Next.js onboarding.

## When to use
- During adapter-based onboarding for Next.js projects.

## Checklist
- [ ] Adapter installed
- [ ] Environment configuration validated
- [ ] Workspace mapping confirmed
- [ ] Health checks pass
- [ ] Content update path validated
- [ ] Forms/enquiries route validated
- [ ] Handoff completed

## Expected result
Next.js project is connected and operationally ready.

## Troubleshooting
- If health is unstable, confirm environment parity and collect deployment logs before escalation.
