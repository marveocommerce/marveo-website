# Install Next.js Adapter

## Purpose
Set up the Marveo adapter for Next.js projects so operational controls can connect to your frontend workflow.

## When to use
- You have a Next.js site and want Marveo-managed operational workflows.
- You are onboarding a headless or frontend-led stack.

## Setup steps
1. Confirm your project runs in a supported Next.js environment.
2. Add the Marveo adapter package based on your onboarding instructions.
3. Configure required adapter settings from the onboarding checklist.
4. Run local validation.
5. Connect the project to the target Marveo workspace.

## Expected result
- Adapter is recognized by Marveo.
- Workspace can track core operational state for the connected site.

## Troubleshooting
- Build errors after install: verify package version compatibility.
- Adapter not detected: re-check configuration path and environment settings.
- Runtime mismatch: validate Node and Next.js versions with support.
