# Connector Verification Checklist

## Purpose
Provide a fast verification checklist for WordPress connector onboarding.

## When to use
- Immediately after connector installation.
- Before support marks setup complete.

## Checklist
- [ ] Connector installed
- [ ] Connector activated
- [ ] Workspace mapping confirmed
- [ ] Verification status is healthy
- [ ] Sync test completed
- [ ] No critical warnings
- [ ] Customer owner notified

## Expected result
Connection is verified and ready for operational rollout.

## Troubleshooting
- If any item fails, pause launch-readiness and move to troubleshooting guide.
